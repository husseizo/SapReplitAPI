## 2026-04-10

### Fixed
- **NeonSyncJob `OrderHeaders` NOT NULL violation** — `CancellationStatus` column was present in `CachedOrder` model and Neon schema but was missing from the `INSERT` statement in `NeonSyncJob.SyncOrdersAsync()`. Added the column and `@cs` parameter; binds to `h.CancellationStatus ?? ""`.

### Changed
- **`InvoiceDeltaSyncJob` interval reduced from 3 min → 1 min** — improves invoice sync latency: worst-case drops from ~3 min to ~1 min; average from ~1.5 min to ~30 sec.

---

## 2026-04-09 (Migration fixes)

### Fixed
- **`PendingModelChangesWarning` on startup** — EF Core model/snapshot mismatch caused by:
  1. Shadow property `CachedTodayOrderDocEntry` being generated by `.HasOne(l => l.Header).WithMany()` navigation config.
  2. Redundant FK index on `CachedOrderLine`.
- **Migrations added**:
  - `20260409212523_RemoveRedundantOrderLineIndex`
  - `20260412000000_FixTodayOrderLineRelationship`
- **Model fix**: `CachedTodayOrderLine.Header` and `CachedOpenOrderLine.Header` navigation properties made nullable.

---

## 2026-04-08 (Critical fixes)

### Fixed
- **Data loss on startup** — `Program.cs` was calling `db.Database.EnsureDeleted()` + `EnsureCreated()` which wiped the entire SQLite cache on every start. Replaced with `db.Database.Migrate()`.

### Security
- SAP password and Neon connection string identified as plaintext in `appsettings.json`. Credentials moved to environment variables for SAP section (already wired via `IOptions<SapSettings>`). Neon pending.

---

## Earlier (Initial development)

### Added
- .NET 8 Web API with SAP Business One COM interop (`SAPbobsCOM`)
- SQLite cache via EF Core 9 (`CacheDbContext`)
- Neon PostgreSQL mirror via Npgsql (`NeonDbContext`) — optional
- 12 Quartz background sync jobs (delta + full) for Products, Orders, Invoices, Customers, Today Orders, Open Orders
- `NeonSyncJob` mirroring SQLite → Neon every 5 minutes
- `IBackgroundTaskQueue` + `QueuedHostedService` for fire-and-forget controller triggers
- Serilog logging with per-job file sinks
- Swagger / Swashbuckle at `/swagger`
- WAL mode enabled on SQLite at startup
- SAP credential validation at startup via `ValidateOnStart()`
- 8 API controllers: Products, Customers, Orders, Payments, Dashboard, TodayOrders, OpenOrders, Users
- `SyncMetadata` watermark pattern for delta sync state
- `[DisallowConcurrentExecution]` on all sync jobs
- `SemaphoreSlim` lock in `InvoiceCacheService` (45s timeout) to prevent delta/full collisions
- ngrok tunnel configuration for external access
